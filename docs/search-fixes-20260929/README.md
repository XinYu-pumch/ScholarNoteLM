# 检索助手与执行队列修复（2026-09-29）

## 变化

- 流式回复仅在跟随最新状态下自动滚动。向上滚轮、键盘上翻和拖动滚动条立即暂停跟随；滚回底部或点击对话目录中的“回到最新”恢复。避免原先 90px 阈值吞掉小幅上翻。
- 每个完整闭合的 PubMed 代码块就地显示“复制检索式”和“发送到检索式管理”，流式输出期间即可使用。兼容大小写标签、未标语言但具有明确 PubMed 语法的代码块、缺少结构化元数据的历史回答；未闭合的块不提供发送按钮。旧版独立存储的检索式仍可显示。
- “执行全部”只运行启用、未归档、非导入、已填写且缺失 XML 或检索条件变化的策略，前后端均核对。JCR 保存时已经使用已有 XML 重新筛选，不重复联网获取。检索式正文、日期、排序、数量及获取模式变化才需要重新抓取；修改后又恢复原条件时可以复用原 XML。单条播放按钮仍允许主动重新执行。
- 批量及单条执行期间均可“中止执行”。取消覆盖队列间隔、NCBI 限流锁等待、重试等待、HTTP 连接及响应读取。中止标记按项目、检索式、执行编号隔离；与最终结果发布互斥，保留旧 XML 和已经完成的结果。
