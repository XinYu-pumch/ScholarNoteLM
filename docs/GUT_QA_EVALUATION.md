# gut 文献问答：上下文与证据复用评估

本测试集依据本地 `workspace/gut/pubmed/current.xml` 与 Markdown 设计，不是预先生成的学术答案。不要把下面的评估说明和预期行为一起发给模型；每次只粘贴问题。

## 文献基础

项目内至少有以下相关材料：

- PMID 32901017，*Intestinal microbiota-derived short-chain fatty acids regulation of immune cell IL-22 production and gut immunity.* 本地有全文及图片，适合核对细胞类型、实验对象、受体与 HDAC 机制及图文关联。
- PMID 38565643，*Short-chain fatty acids: linking diet, the microbiome and immunity.* 适合补充整体机制背景，不能把综述对其他研究的转述自动视为本项目已读到原始实验。
- PMID 30915065，*Short Chain Fatty Acids (SCFAs)-Mediated Gut Epithelial and Immune Regulation and Its Relevance for Inflammatory Bowel Diseases.* 本地有全文及图片，适合区分机制解释与临床应用证据。

这些是评估时可检查的相关文献，不是强制答案必须引用的名单。检索仍然针对正文 chunk；本测试不要求用篇名检索。

## 初始设置与主问题

选择 gut 项目、全部项目文献、主题问答；保留当前检索轮次设置；自动补入整篇全文的功能已删除，无需设置开关。图像测试需要把实际支持视觉的回答模型设为视觉模型。模型名称或勾选本身不能证明它真的收到或理解了图片。

新建对话，发送：

> 肠道菌群产生的短链脂肪酸，尤其是丁酸，如何影响人源 CD4+ T 细胞的 IL-22 产生？请分别讨论受体信号、HDAC 抑制、下游转录调控，以及这些变化与肠黏膜屏障和炎症的关系。先聚焦人源细胞实验和临床证据；如果某条机制实际上只在小鼠或体外实验中得到支持，请明确区分，不能把机制证据写成已证实的临床疗效。

这道题能拆为不同证据维度，又有明确的“物种—细胞—机制—结局”边界。它尤其适合观察模型是否把不同实验的证据拼接成一个不存在的完整结论。

## 不同类型的追问

主问题回答成功后，复制该对话，每类追问在一个副本里测试。这样每次都基于同一份正式回答，不会被其他测试追问改变语境。最后再做一次连续追问测试。

## 推荐的一条连续测试路径

主问题 → “那小鼠呢？” → “那 ILC3 呢？” → “把刚才的回答压缩到约 200 字，保留引用” → “你压缩后保留的第二个机制结论有什么原文依据？” → “对照我最初问的人源证据和你后来补充的小鼠证据，哪些机制两者都有支持？”

这能测试：短追问的语境补全、跨轮引用取回、纯改写后仍能追溯原文，以及更早轮次的指代。对“第二个机制结论”有歧义时，直接粘贴真实句子；不要把合理澄清视为失败。

## 如何判定问题在哪里

1. **路由与执行**：在“检索与核对过程”核实是否实际执行检索，而不是只看回答说了什么。纯改写与闲聊应为 0 轮；依据追问可能仅取历史证据，也可能补检索。耗时不能单独说明走了哪条路径。
2. **上下文**：查看本轮运行记录 `input.json` 的 history 是否包含此前用户问题与成功的正式回答；不应把失败草稿当成已确认结论。复制对话后，应能解析同样的历史指代。
3. **证据复用**：需要历史依据时检查 `history-evidence.json` 与本轮证据记录。E/R 编号在新轮可以重新编号；应该比较 PMID、稳定原文块/资源 ID 及对应内容，而不是要求 E1 永远不变。
4. **引用**：点击 PMID 核对支持它的原文。确认“人源细胞”没有被写成患者试验，综述背景没有被写成原始实验，某个实验的剂量/结局没有被挪到另一个实验。
5. **图表**：正文表格每行的来源应可追溯；原图应能找到实际发送的图片和其来源。没有合适原图时不插图，是可以接受的结果。
6. **归因**：如果正式历史没有被载入、纯改写仍强制检索、旧引用绑定丢失、ID 指错原文，优先查程序；如果正确原文已发送但物种/细胞/实验条件被模型误读，优先归为模型理解问题。召回根本未提供关键段落时，不能只怪回答模型。

建议记录“问题文本、实际路线、检索轮数、历史证据是否取回、2–3 个抽查论断与来源、问题归因”。每项按通过/失败/证据不足标记。当前评估围绕正文召回、位置关联图表和按需历史引用，不再做全文补读开关对照。
