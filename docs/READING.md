# 阅读与笔记

单篇全文对话不设问题字符上限，仍发送完整未清洗 Markdown（无全文时用摘要）及已有成功轮次；不自动截断，模型服务的上下文超限错误照常呈现。

阅读页以单篇论文为中心，和项目范围的文献问答独立。按项目 + PMID 隔离对话，不需要索引或 Embedding。旧版单篇精读的 RAG/agent 流程仍未恢复。

## 阅读与导航

- 顶部下拉框按标题或 PMID 搜索；方向键选择，Enter 确认，Escape 关闭。
- 有 PDF 时直接显示只读 PDF，所有页面竖向连续排列，可自由滚动；支持页码跳转、10%–800% 自定义缩放、加减按钮、触控板捏合或 Ctrl/Command + 滚轮缩放、适合宽度、选中文字复制及按匹配页查找。缩放时保持当前页内阅读位置，放大后可横向滚动。扫描件没有文字层时不能直接查找文字。
- 无 PDF 时显示当前 PubMed 记录生成的摘要 Markdown，只读。不会把清洗后的全文误当摘要。
- PDF.js 按需加载，仅可见及附近页面持有画布，远处页面保留尺寸占位；大倍率下限制画布像素，避免长论文或放大时内存激增。worker、字体、CMaps 和解码器由本地应用提供，不使用 CDN。不会把 PDF 复制进对话目录。
- 连续缩放输入按屏幕刷新帧合并，过程中缩放现有画布和文字层，保持手势焦点；暂停约 180 ms 后才按新倍率补绘。新画布和文字层准备完成后一起替换旧版本，避免空白闪烁。预览阶段可能暂时略模糊，补绘完成后恢复清晰。WebKit 同时发送捏合和滚轮事件时不会重复放大。
- 右侧聊天栏可收起；中间分隔条可拖动或用左右方向键调整。聊天区和论文分别滚动，输入框固定在侧栏底部。
- 文献库详情、全局搜索、问答证据与综述引用/证据提供阅读入口。返回时恢复原页面的现有页面状态。已移出当前集合的引用会提示先添加文献，不会跳到另一篇。
- 直接进入阅读页时恢复最近阅读的文献；项目概览入口已移除。恢复 PDF 页码、缩放、页内相对位置、横向滚动位置和最近对话，兼容旧版单页阅读记录；PDF 内容变更后重置其阅读位置。

## 对话与模型

可新建、重命名、删除当前论文的对话；每个对话可选择设置中的 LLM。Enter 换行，Command/Ctrl + Enter 发送；输入法组合期间不触发快捷键。模型回答支持流式显示和停止，每轮回答下方提供：

- **复制**：复制该轮回答正文。
- **重新生成**：使用当前选择的模型重新回答。最后一轮在原对话中替换；历史轮次自动创建新分支，包含此前成功问答及重新生成的当前回答，保留原对话和后续追问。
- **从这里开始分支**：复制截至该轮的完整问答，切换到新对话继续追问；仅已完成回答可作为分支点。原对话后面正在生成时，也能从此前已完成回答创建分支。

分支与原对话共享同一全文快照，不复制 PDF 或原始 Markdown；删除原对话不影响仍引用快照的分支。消息有稳定标识，页面上过期的重新生成/分支操作会被拒绝，避免误操作另一轮。失败或停止后需重新生成该轮或新建对话，也可从此前成功回答创建分支，避免把不完整回答当作成功历史。

请求包含系统提示词、完整材料、此前成功问答及当前问题。系统提示词要求基于论文回答、区分作者发现与推断、标明摘要限制，不编造引文/页码；论文内容被标注为资料而非指令。

全文严格来自 `markdown/raw/<PMID>.md`，保留参考文献等未清洗内容，不经过向量检索、分块或摘要压缩。原稿中的文字、表格、图注会发送；Markdown 图片链接不表示模型看到了原图。每次请求都发送全文，但磁盘上不会每轮重复存储。

PDF 存在但缺少原稿或转换指纹过期时，新对话暂不能发送，提供“转换这篇文献”（复用单篇转换，不自动建立索引）。没有 PDF 时使用摘要，不依赖下载阶段是否已结束。

不自动截断全文，普通 OpenAI 兼容请求不添加输出 token 限制；Go 原生 Messages 协议的必填输出参数见 [供应商说明](../services/llm_providers/README.md)。供应商拒绝超长请求时保留问题与已收到的回答并提示更换模型；新建对话只能减少历史长度，不能缩短全文。

## 保存、版本与任务

```text
reader/
  reader.sqlite3           # 对话、消息、模型标识、运行状态、阅读位置
  sources/<sha>.json.gz    # 同一完整材料版本共享一个 gzip 快照
  <thread-id>.lock         # 后台进程锁
notes/notes.json           # 原有手写笔记，继续独立保存
```

第一轮发送时固定材料版本。后续即使 PDF 或 Markdown 更新，旧对话继续使用原快照并显示旧版提示；新对话使用当前有效材料。同项目、同论文、同版本的多个对话复用快照。删除最后一个引用该快照的对话时回收快照。清理下载/转换/索引产物不会删除阅读记录与对话。

`reader.*` RPC 由 Rust 转交 Python；`reader_worker.py` 独立执行流式请求，切换页面不终止生成。SQLite 事务限制同一对话只能有一个活动请求，不同对话可独立生成。取消状态与 run ID 防止晚到结果覆盖新任务；进程锁用于识别异常退出。阅读任务计入项目使用状态，项目删除/移动/清理遵守现有互斥流程。

模型密钥只在工作进程中从配置读取，不写到对话、命令行或全文快照。不记录重复的完整请求日志。手写笔记仍在阅读页底部折叠入口，原有内容保留。

## 验证

```sh
runtimes/downloader/bin/python -m unittest discover -s services/downloader/tests -p test_reader.py
runtimes/downloader/bin/python scripts/test-reader-integration.py
```

集成脚本使用 `tmp/` 下的隔离根目录、本地 SSE 模型、8 页模拟 PDF/XML，经过实际 Rust RPC 和独立 Python 工作进程。覆盖超过 20 万字符原稿、连续追问、模型切换、快照共享、摘要回退、停止/重试、分支续问、历史回答重新生成和上下文错误。`--serve` 在验证完成后保留临时项目和本地服务供 UI 检查；退出后自动清理。不要将开发服务器指向真实研究项目运行 UI 测试。

连续缩放回归使用 `scripts/test-reader-zoom.html`：将另一个 Vite 服务的 `SCHOLARNOTELM_ROOT` 指向上述隔离目录（可用 `run dev -- --port 1421` 保留当前开发版），通过该服务的 `/@fs/<仓库绝对路径>/scripts/test-reader-zoom.html` 打开测试页，再进入下方应用的阅读页。测试按钮产生连续滚轮或 WebKit 捏合事件，检查画布没有中途替换/消失、停下后只替换一次、焦点漂移和最终倍率，以及高清文字层恢复。测试页拒绝非隔离项目；数据及截图不提交。


### 双语行为

阅读对话有独立回答语言，默认取设置中的新内容语言。后续切换只影响新提问，运行中的回答使用开始时快照；重新生成和从指定轮次分支沿用该轮语言。原始全文 Markdown 和摘要不因界面语言变化而翻译。
