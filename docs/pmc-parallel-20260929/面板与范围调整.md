# PDF 操作区与 PMCID 范围调整

- 文献库保持四栏固定布局，统一指标、说明和底部操作的位置与间距。
- “更多”菜单增加分组标题、统一图标和整行点击区域；清空操作使用红色与分隔线，选中后关闭。
- 菜单通过原生 Popover 顶层显示，避免滚动容器裁剪；按按钮定位，窄窗口时限制在可见范围内。点击外部、Escape 关闭，展开不挪动主按钮。
- PMC 双路队列只收录已有合法 PMCID 的文章；S3 正序、getPdf 倒序和失败互补机制保留。删除 S3 中按 PMID 查询 PMCID 的行为。
- 缺少/无效 PMCID 的文献不调用这两个来源，照常进入 Sci-Hub、Unpaywall 等后续流程。

验证：67 项后端回归通过；前端类型检查与生产构建通过。Chromium 与 WebKit 界面测试均通过，覆盖 1512 / 1232 / 1000 / 800 宽度的主按钮点击区域、菜单位置与尺寸、所有菜单项底部的真实命中、选中后关闭、外部点击与键盘退出。真实项目文件未修改。
