五项统一规范

01 动画

反馈 100–120ms；标签 160ms；面板 200ms；弹窗 220ms。无弹跳，支持减少动态效果。

02 按钮

默认 34px，工具栏 28px，圆角 7px。主、次、文字、危险动作各有明确语义。

03 布局

48px 顶栏，24px 页边距；内容优先。辅助栏按窗口宽度收起，不缩小正文来容纳。

04 配色

中性色承担结构，墨蓝仅用于交互。完成状态用图标和文字，深色模式另设层级。

05 字体

系统 UI 13–14px，正文 16/27px，元数据 12/18px；衬线字体仅用于阅读，检索式用等宽。
