# Design System 验收矩阵

[主规范](../UI_DESIGN.md)是契约入口。本文件定义后续组件与页面迁移的验收范围，不是通过报告；每次提交按改动范围标记通过、失败、未测或不适用，并附原因。截图用于核对布局，不替代行为断言。

## 1. 平台与组合

| 维度 | 首批要求 | 不得混淆的边界 |
| --- | --- | --- |
| 运行环境 | macOS Tauri 实机；浏览器辅助定位 | 浏览器通过不等于 WKWebView 通过；Windows 未实测不得标通过 |
| 窗口 | 1440×940、1024×768、900×650 | 900×650 来自当前 Tauri 最小窗口配置；760×900 与 360px 为浏览器压力检查 |
| 主题 | 浅色、深色 | 检查实际表面、文字、图标与焦点组合，不只检查 token 名称 |
| 输入 | 鼠标、键盘、中文输入法 | 键盘检查不能用鼠标替代；中文组合阶段不得误发送 |
| 内容 | 空、少量、长标题、深层大纲、长正文、长模型名 | 不使用真实研究数据或密钥 |
| 动效 | 默认、减少动态效果 | 关闭动画后仍能理解状态与完成操作 |
| 文字放大 | 浏览器 200% 文本/页面缩放的适配诊断 | 记录采用的缩放方式；不把 PDF 缩放当成界面放大 |

不是每次修改都跑完整笛卡尔积。组件变更至少覆盖正常、禁用/加载/错误中适用的状态、键盘、双主题和最窄目标窗口；页面迁移再覆盖下表对应流程。P3 完整验收记录跨维度覆盖情况与未测项。

## 2. 页面与业务状态

| 页面 / 模式 | 场景 | 必须观察的结果 |
| --- | --- | --- |
| 文献来源 | 空来源、筛选变化、导入中、部分检索失败 | 主动作及禁用原因清楚；导出 XML 只在文献来源；旧结果不因失败消失；更多菜单不越界 |
| 检索助手 | 无对话、长输入、流式输出、模型失败 | 输入始终可达；发送快捷键正确；失败保留输入；对话管理不混入来源工具栏 |
| 文献库 | 无 PDF、有摘要；批量选择；部分下载失败 | 任务结束不显示为全文齐全；批量动作范围清楚；错误不能带成功勾号 |
| 综述大纲 | 空大纲、深层树、长文编辑、生成失败、切换工作区 | 设置按需展开；保存入口共享草稿；离开保护正确；失败保留原结果 |
| 综述撰写 | 待准备、准备中、部分完成、重试、停止、需更新 | 全文节数与本轮组数分开；重试保留已完成成果；只锁定冲突操作；原有正文保护生效 |
| 撰写设置 | 编辑后关闭、取消、Escape、遮罩；保存失败 | 四种离开路径一致；保留/放弃语义明确；失败不丢草稿；无隐藏 dirty 禁用主动作 |
| 文献问答 | 多轮、分支、重新生成、引用定位 | 消息动作范围一致；精确证据定位不降级；向上阅读时不被流式输出抢回底部 |
| 阅读与笔记 | 有 PDF、仅摘要、文献切换、窄窗、笔记保存失败 | PDF/摘要只读；连续缩放平滑；聊天/正文均可达；草稿不串文献；保存失败可见 |
| 模型设置 | dirty 时换配置/分组/页面；保存失败 | 先处理原草稿再导航；失败通知正确；保存结果不重复出现；报告不包含密钥 |
| 删除确认 | 取消、确认、正在执行、部分文件删除失败 | 确认文案写清对象与永久性；危险动作显式命名；无虚假回收站或撤销承诺 |
| 任务中心 | 排队、未知总量、读取失败、部分完成 | 未知不显示为 0/成功；阶段、分母、成功数量和恢复动作真实 |

## 3. 通用组件行为

| 组件 | 键盘 / 焦点 | 关闭 / 状态 |
| --- | --- | --- |
| Button / IconButton | Tab 可达、Enter/Space 可执行、焦点可见 | busy 防重复；禁用原因关联可读；图标有名称 |
| Select | 方向键、Home/End、输入匹配、Enter 选值 | Escape 取消、焦点返回；长选项不撑破窗口 |
| Tabs | 方向键、Home/End、roving tabindex | 焦点与选中区分；代价高/有草稿时手动激活；tabpanel 正确关联 |
| Disclosure | Enter/Space 展开，内容按普通 Tab 序列访问 | 展开语义真实；不伪装成缺失菜单键盘操作的 ARIA menu |
| Portal menu | 方向键遍历、首尾、Escape | 避让边缘、不被裁切；菜单转弹窗的焦点不能被入口抢回 |
| Dialog / ConfirmDialog | 可访问名称、合适初始焦点、模态焦点范围 | 关闭遵循草稿契约；危险确认不因普通输入 Enter 意外触发 |
| SplitPane / Inspector | 分隔条支持键盘，关闭可达 | 调宽有上下限；窄屏收纳；关闭后返回来源 |
| 通知 / 状态 | 关键变化可感知，不逐 token 播报 | severity 正确；同一事件去重；错误恢复入口不瞬间消失 |

## 4. 保留与证据专项

- 同项目返回：选中条目、章节和滚动位置按契约恢复；切换项目后不串用状态。
- 重启恢复：只验证明确持久化的项目；进程内 page-memory 不计为持久能力。
- 草稿：继续编辑保持原值；明确放弃才清除；保存失败保持原输入；密钥草稿不进入普通状态记忆或测试报告。
- 引用：逐项核对 PMID 组定位、证据 ID 定位、文献弹窗各自精度，不用统一样式掩盖差异。
- 核查：格式/引用一致性与科学真实性分开表达。
- 离线 HTML：将新导出的文件移到隔离的另一目录，断网后打开；正文、内嵌图片、表格和引用详情可用，外部论文链接单列。验证自包含性，禁止改成依赖应用资源路径。导出主题与打印行为按实际能力单独记录，不默认等同于桌面。

## 5. 测试与记录

先阅读脚本再执行。所有写操作使用 `tmp/` 的隔离 SCHOLARNOTELM_ROOT、本地模型模拟服务与虚构文献；连接 Vite 时先确认隔离根目录，不直接操作用户在 1420 上的开发项目。

`scripts/visual-check.mjs` 当前仍依赖已移除的保存状态和项目概览，不能直接作为有效基线。先更新断言和隔离启动方式，再复用；其余脚本也逐个核查。不要为了让旧截图通过而恢复已删除 UI。

视觉变更按范围运行构建与样板/页面检查；综述、问答、向量、下载行为受影响时追加对应隔离集成测试。仅文档变更验证链接与一致性，按仓库要求完成构建，不运行真实研究任务。

每次记录：提交号、环境、窗口、主题、输入方式、用例、预期、实际、结果、截图/日志位置、未测限制。截图和结果 JSON 是忽略的运行产物，不提交；更新规范应写规则和结论，不在 docs 新增按日期堆积的报告。
