# 2026-09-28 应用精简与界面整理

## 完成的改动

- 文献问答与检索助手的对话侧栏统一为 190 px，较窄窗口使用 165 px，并可收起。长标题省略显示，不再撑宽侧栏；回答表格在正文区域横向滚动。
- 两种对话都增加“对话目录”：按用户提问编号、搜索问题、跳转对应消息、回到最新。定位历史问题后不会因状态轮询自动滚回底部。
- 可用模型列表内合并启用、支持图片、默认模型、连接测试及图片测试。图片测试发送本地生成的随机纯色图片，核对返回颜色；普通连接测试不代表视觉能力。连接参数变化会清除旧测试显示。
- 删除“召回与重排”页面。当前 Embedding 配置同时负责文献向量化与查询向量；RPM、TPM 归入该配置的高级参数。保存其他配置不会自动切换已有活动配置；启用前要求验证通过。
- 转换固定使用 Marker 1.6.0；参考文献清洗内置启用，无清洗策略开关。正文、短段、图注、表格等仍保留。短 heading 召回排除和长 heading 保留规则不变。
- 移除 Qwen 重排、MedCPT、BM25 排序、PaddleOCR 的执行代码与相关模型，以及 Paddle 专用运行环境。主题问答自动选择整篇全文并补入材料池的代码、参数和提示已删除。历史引用按需取回、单篇精读和项目概览仍是各自原有功能。
- 删除检索助手常驻分支说明，简化问答、转换、索引和来源操作的文字。必要的删除范围与错误原因保留。
- 文献库各卡片“更多”改为独立浮层，不增加卡片高度；同一时刻只打开一个，支持 Escape、移出焦点和点击外部关闭。

## 数据与迁移

旧全局 RPM/TPM 仅用于填补 Embedding 配置中尚未独立保存的值；已有配置值优先。当前安装已完成迁移并删除旧 `config/retrieval.json`。修改限速不改变模型指纹、验证记录或向量缓存身份。

原始 Markdown、既有清洗稿、图片、问答记录及引用快照没有批量重写。已使用 `references-only-v2` 的 Marker 文献保持既有清洗签名；旧引擎来源仍如实保留，后续更新使用 Marker。新检索策略签名会让旧综述提示词需要重新准备，正文向量缓存仍可复用。

删除清单位于 `logs/app-simplification/removed-components.json`：12 个路径，文件逻辑大小合计 4,879,366,886 字节（约 4.88 GB）。逻辑大小不等于实际释放磁盘空间。移除了 6 个无源文件的旧 Python 字节码。备份位于 `backups/app-simplify-20260928-154957/`，保留源码和旧配置用于回退，不保留删除的模型副本。

对 gut 项目事前记录的 145 个问答/Markdown 文件逐一复核 SHA-256，全部一致。清单位于 `logs/app-simplification/preserved-files.json`。
