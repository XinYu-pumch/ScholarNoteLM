# 统一检索筛选与文献库点击区域修复

检索式管理新增「统一 JCR / 日期」。日期、JCR 可一起或分别应用到当前所有未归档条目（包含停用条目），应用后仍能逐条调整。检索式文本、排序和数量保留各自设置；新增条目保持原有默认行为。导入 XML 无法重新发起 PubMed 检索，因此只应用 JCR。

批量修改使用一个数据库事务，先校验日期与 JCR 参考文件，避免部分保存。日期变化使已有检索结果待更新，JCR 保存后在本地重新筛选已有 XML。沿用 query 写操作的材料缓存失效机制。

点击问题根因：旧的 `.stage-more { width:100% }` 与横向工具条、禁止收缩的样式叠加，使前一张卡片的透明 details 区域覆盖后一张卡片的按钮。改为按内容占宽，按钮不压缩；可用宽度不足时改两列并允许工具栏换行，按钮高度统一为 36 px。

另修复 WebKit 下点击“更多”菜单按钮时 summary 先失焦、菜单过早关闭的问题。现在内部指针操作期间保留菜单，点击外部、键盘离开及 Escape 仍能关闭。
