# ScholarNoteLM 界面设计规范

2026-10-04 起生效，取代此前的“暖白 / 墨绿 / 原型”说明。所有数值都来自 `apps/desktop/src/tokens.css`；组件规则集中在 `apps/desktop/src/design.css`，它最后加载。新增界面只使用这些 token，不写死颜色、字号、圆角、阴影和时长。

## 1. 方向：纸、墨与秩序

ScholarNoteLM 是一张安静的研究书桌，不是控制台。参照苹果的克制：

- 用留白和字重建立层级，不靠分割线和色块。
- 色彩只用一种墨蓝强调色，其余靠暖中性灰阶。语义色只在状态上出现。
- 标题使用衬线体，带出学术出版物的气质；界面控件使用系统无衬线体，保持清晰。
- 表面分三层：画布、卡片、浮层，用极轻的阴影区分，不用粗边框。
- 动效只表达因果，例如出现、展开、确认，短而柔和，并尊重“减少动态效果”设置。

## 3. 字体

| token | 字体栈 | 用途 |
| --- | --- | --- |
| `--font-ui` | SF Pro Text → 苹方 → Segoe UI → 微软雅黑 | 界面、控件、正文 |
| `--font-display` | New York（`ui-serif`）→ 宋体-简 → 思源宋体 → Georgia | 页面标题、章节标题、文献篇名 |
| `--font-reading` | 同 `--font-display` | 综述正文、阅读页摘要 |
| `--font-mono` | SF Mono → Menlo → Consolas | 检索式、代码、编号 |

字号阶梯沿用 macOS 文本样式，界面默认 13px，内容默认 14px：

| token | 大小 / 行高 | 用途 |
| --- | --- | --- |
| `--fs-caption` | 11 / 1.4 | 分组标签、计数 |
| `--fs-footnote` | 12 / 1.45 | 元数据、辅助说明 |
| `--fs-subhead` | 13 / 1.5 | 控件、表格、导航 |
| `--fs-body` | 14 / 1.6 | 正文、输入内容 |
| `--fs-callout` | 15 / 1.6 | 对话正文、强调说明 |
| `--fs-headline` | 17 / 1.4 | 卡片标题、区块标题 |
| `--fs-title3` | 20 / 1.3 | 次级标题、弹窗标题 |
| `--fs-title2` | 24 / 1.25 | 统计数字、阅读标题 |
| `--fs-title1` | 30 / 1.2 | 页面标题（衬线） |

字重只用 400、500、600 三档，不用 700。页面标题使用衬线体 600、字距 -0.01em；数字统一使用等宽数字（`tabular-nums`）。

## 4. 布局

- **窗口结构**：侧栏 236px，半透明石灰底、右侧发丝线。顶栏 52px，与画布同色，只保留面包屑、保存状态、帮助和主题切换。
- **页面**：左右内边距 40px，顶部 32px。页面标题区由衬线标题加一行说明组成，与内容间隔 28px，不再用分割线。
- **栅格**：间距只用 4 / 8 / 12 / 16 / 20 / 24 / 32 / 40。卡片内边距 20px，卡片之间 16px。
- **卡片**：圆角 14px，发丝线描边加 `--shadow-xs`。卡片内的次级区域使用 `--panel`，不再嵌套描边。
- **表格**：无竖线；行高 52px 起；表头 12px 次要色；悬停时行底变为 `--row-hover`。
- **阅读宽度**：问答回答、综述正文、阅读页正文限宽 760px。

## 5. 按钮与控件

| 类型 | 外观 | 用途 |
| --- | --- | --- |
| 主按钮 `.button.primary` | 墨蓝实底、白字、顶部高光、`--shadow-xs` | 每个区域最多一个 |
| 次按钮 `.button.secondary` / `.button` | 白底、发丝线描边、`--shadow-xs`，类似 macOS 推按钮 | 常规操作 |
| 文字按钮 `.text-button` | 无底，强调色文字，悬停出现淡底 | 次要链接式操作 |
| 图标按钮 `.icon-button` | 30px 方形，悬停出现中性淡底 | 工具栏 |
| 危险 | 红色文字；确认弹窗内用红色实底 | 删除、清空 |

- 高度：常规 32px，紧凑 28px，大号 36px。圆角统一 8px，胶囊形用于标签和计数。
- 按下时缩放到 0.98（80ms），悬停只改变颜色或底色（140ms），禁用时透明度 0.4。
- 输入框与下拉框：高 34px、圆角 8px、白底发丝线；聚焦时边框变为强调色，外加 3px 半透明焦点环。
- 标签页：页面级（文献来源 / 检索助手、综述大纲 / 综述撰写）使用分段控件；文献库的筛选使用带下划线的文字标签。
- 状态标签：胶囊形、11px、淡底配同色文字，语义色只在这里出现。

## 6. 阴影与层级

| token | 用途 |
| --- | --- |
| `--shadow-xs` | 按钮、输入框、卡片 |
| `--shadow-sm` | 悬停的卡片、选中的分段 |
| `--shadow-md` | 下拉菜单、浮层、提示 |
| `--shadow-lg` | 弹窗 |

浮层和弹窗配合 `backdrop-filter` 模糊；弹窗遮罩为墨色 18% 加 6px 模糊。

## 7. 动效

| token | 时长 | 用途 |
| --- | --- | --- |
| `--dur-press` | 80ms | 按下反馈 |
| `--dur-fast` | 140ms | 悬停、颜色变化 |
| `--dur-base` | 200ms | 菜单、标签切换、展开 |
| `--dur-slow` | 280ms | 弹窗、抽屉、页面进入 |

- 缓动：`--ease-out`（`cubic-bezier(.22,1,.36,1)`）用于进入，`--ease-in-out` 用于往返。不用弹跳。
- 标准动画：
  - `rise-in`：页面与列表进入，位移 6px 加淡入。
  - `pop-in`：菜单与浮层，从 0.97 缩放加淡入。
  - `dialog-in`：弹窗，从 0.96 缩放加淡入。
  - `fade-in`：遮罩与提示。
  - `spin`：加载。
- 页面切换只让内容区执行 `rise-in`，侧栏和顶栏保持静止。
- 系统开启“减少动态效果”时，所有过渡与动画缩短到 1ms，只保留结果。

## 8. 页面要点

| 页面 | 目的 | 视觉重点 |
| --- | --- | --- |
| 检索工作台 | 管理文献来源与检索式 | 分段控件，轻量表格，检索式使用等宽字体 |
| 文献库 | 以篇名为中心浏览与处理 | 篇名使用衬线体，状态胶囊，处理流程卡片 |
| 综述工作台 | 大纲、撰写与证据 | 正文使用阅读字体并限宽，证据为右侧卡片 |
| 文献问答 | 问题与可追溯回答 | 对话居中，输入框悬浮于底部 |
| 任务中心 | 后台任务进度 | 进度条、状态胶囊、清晰的时间信息 |
| 设置 | 配置模型与服务 | 左侧分组导航，右侧表单卡片 |

文献库是默认首页，不再单列项目概览。检索助手标题保持单行，与导航按钮和模型选择器垂直居中。文献条目不显示单篇“下载”按钮，批量下载和文献处理流程保留。问答输入区只保留文献范围与发送控件，新提问统一为主题问答；引用详情不显示内部哈希、原文快照说明和“复制原文”按钮。

## 9. 不变的约束

- 只改外观，不改任何交互与功能：组件结构、文案、按钮行为、键盘操作保持不变。
- 所有字体和图标都来自本地系统或依赖，不加载远程资源。
- 浅色与深色主题同步维护。文字色在画布、卡片和侧栏上都满足 WCAG AA（4.5:1）：正文约 15:1，次要色 5.6:1 起，弱化色 4.6:1 起，强调色 7:1 起。
- 不要给包含 `position: fixed` 子元素的容器（例如侧栏）加 `backdrop-filter` 或常驻 `transform`，否则点击外部关闭的透明遮罩会被限制在容器内。动画一律使用 `backwards` 填充，结束后不残留 transform。
