# ScholarNoteLM Design System · 1.0

面向长时间阅读、文献整理和基于证据的写作。设计目标：**研究内容占主位，操作紧邻对象，过程可理解，成果可追溯。**

本文取代旧版界面设计规范，是后续设计与开发的共同依据；不是全站改造已经完成的声明。本次交付为规范与交互样板，不改变应用行为。现有产品约定见 [README](../README.md)，实际功能以源码及对应专题文档为准。未实现的组件契约和跨页行为列入第 13 节的迁移计划，不能仅修改文案就宣称具备功能。

## 1. 设计原则与边界

| 原则 | 在 ScholarNoteLM 中的具体判断 |
| --- | --- |
| 内容优先 | 阅读、综述、问答页面首屏应能看到正文或输入区；设置与日志不能长期挤占内容 |
| 对象先于动作 | 先明确当前项目、工作区、文献或对话，再提供作用于它的命令 |
| 位置可预测 | 同类操作保持位置、名称和顺序；任务过程中原位更新状态，避免按钮跳位 |
| 逐步展示 | 常用操作可见；低频命令在更多菜单；复杂参数在设置；核对材料在侧栏 |
| 反馈与影响匹配 | 普通成功轻提示；失败留在现场；不可逆操作清楚说明后果并确认 |
| 保留研究上下文 | 切换与返回尽量恢复选中项、滚动位置和草稿；覆盖正文前遵循已有保存流程 |
| 一致而非同形 | 表格应紧凑，阅读应舒展；视觉和语义统一，信息密度按任务调整 |

借鉴 Apple HIG 的分组、渐进展示和反馈原则，结合本产品桌面研究场景制定下面的尺寸、按钮顺序及任务语义；这些具体规则不是 Apple 的强制要求。保留纸白、墨蓝与阅读字体，不新增大面积玻璃效果、装饰渐变或重复卡片。

本规范不恢复已删除的项目概览、单篇精读 RAG、重排或其他旧功能；不改变提示词、缓存签名、检索算法或自包含 HTML 导出协议。

## 2. 设计系统的层次与唯一来源

| 层次 | 唯一来源 / 责任 |
| --- | --- |
| 产品行为 | 根 README 与各功能专题文档；本文负责统一交互表达 |
| 基础 token | [tokens.css](../apps/desktop/src/tokens.css)：颜色、字体、字号、间距、圆角、阴影、时长 |
| 通用外观 | [design.css](../apps/desktop/src/design.css)：按钮、表单、工具栏、状态与通用表面 |
| 通用交互 | [ui.tsx](../apps/desktop/src/ui.tsx)、[Select.tsx](../apps/desktop/src/Select.tsx)、[ActionMenu.tsx](../apps/desktop/src/ActionMenu.tsx) 等公共组件 |
| 页面组合 | 检索、文献库、综述、问答、阅读页面只选择组件与布局，不自行发明同类控件 |

新增颜色、字号、圆角、阴影和动效必须先进入 token；不在页面中填入临时常量。新增语义别名须映射已有基础值并同时覆盖浅深色，不复制一套近似色。本文数值供设计查阅，代码值以 token 文件为准。

当前已有样式基础，但不是所有按钮和状态都已收敛为 React 公共组件。后续优先复用现有实现，只有反复出现的差异才抽象，避免为每一行布局建立组件。

## 3. 视觉基础

### 3.1 颜色：表面、内容、交互、状态

| 语义 / token | 浅色 | 深色 | 使用范围 |
| --- | --- | --- | --- |
| 画布 `--bg` | #F7F6F2 | #141416 | 主页面背景 |
| 内容 `--surface` | #FFFFFF | #1D1D20 | 阅读区、表格、输入控件 |
| 导航 `--sidebar` | #EFEDE7 | #19191B | 主导航 |
| 次级表面 `--panel` | #FBFAF7 | #202023 | 内容内分区 |
| 浮层 `--surface-raised` | #FFFFFF | #262629 | 菜单与浮层 |
| 正文 `--text` | #1C1C1E | #F2F1EE | 主要标签、正文 |
| 次要 `--muted` | #5E5D59 | #A9A8A3 | 参数摘要、作者、日期 |
| 辅助 `--faint` | #6B6A65 | #94938E | 非关键注释，不用于必读操作说明 |
| 强调 `--accent` | #24527A | #8FB6DD | 主动作、链接、选中和焦点 |
| 强调底文字 `--on-accent` | #FFFFFF | #0F1A26 | 必须与强调底配对，深色模式不沿用白字 |
| 成功 `--green` | #2E6B4F | #7CC4A0 | 已完成、校验成功 |
| 注意 `--ochre` | #946312 | #E2B66B | 需更新、部分完成、前置条件缺失 |
| 危险 `--red` | #B23A3A | #F08C8C | 失败、删除 |

选中用 `--accent-soft`，悬停用 `--hover`，按下用 `--pressed`，焦点用 `--focus-ring`；四者不能互相替代。选中和错误均要有文字、图标或可访问状态，不能只靠颜色。

边框默认 `--line`；需要辨识输入边界时用 `--line-strong`。不要假设发丝线必然满足控件边界对比度要求；以实际组合验收。

### 3.2 排版：界面与阅读分工

| 用途 | 字体 token | 字号 token | 字重 / 行高目标 |
| --- | --- | --- | --- |
| 普通页面标题 | `--font-display` | `--fs-title1` 30 | 600 / 1.2 |
| 阅读章节标题 | `--font-display` | `--fs-title2` 24 | 600 / 1.3 |
| 弹窗标题 | `--font-display` | `--fs-title3` 20 | 600 / 1.3 |
| 工作区名称、区块标题 | `--font-ui` | `--fs-headline` 17 | 600 / 1.4 |
| 综述正文、摘要阅读 | `--font-reading` | `--fs-callout` 15 | 400 / 1.8–1.85 |
| 普通正文、表单内容 | `--font-ui` | `--fs-body` 14 | 400 / 1.6 |
| 导航、按钮、表格 | `--font-ui` | `--fs-subhead` 13 | 400 或 500 / 1.5 |
| 元数据、参数摘要 | `--font-ui` | `--fs-footnote` 12 | 400 / 1.45 |
| 紧凑非关键标签 | `--font-ui` | `--fs-caption` 11 | 500 / 1.4 |
| 检索式、PMID、编号 | `--font-mono` | 随所在内容层级 | 400；数值列用 tabular-nums |

只使用 400 / 500 / 600 三档字重。界面控件不使用衬线字体。文献篇名可用阅读字体；作者、期刊、年份和操作使用界面字体。字体只来自本地系统与已有依赖，不下载字体。

长标题不缩小字号挤入控件：列表篇名允许两行，紧凑选择器省略并提供完整名称，正文标题自然换行。输入、错误原因、按钮动作名不能被省略号隐藏。中文与英文模型名混排时保留合适间距；数字和单位作为完整含义展示。

### 3.3 尺寸与形状

| 项目 | 规则 |
| --- | --- |
| 间距 | 4 / 8 / 12 / 16 / 20 / 24 / 32 / 40，使用 `--space-*` |
| 控件内图文间距 | 8；同组控件间距 8；不同动作组 16–24 |
| 页面边距 | 常规横向 40、顶部 32；研究文档页横向 24、顶部 20；窄屏降为 12–16 |
| 按钮 | 紧凑 28、常规 32、对象选择 36；同排同高 |
| 输入框 | 默认 34；与工具栏配对时按整组 32 或 36 统一 |
| 图标 | 工具栏 16；导航 18；行内 14–16；点击区域与同排按钮一致 |
| 圆角 | 控件 8；独立内容面板 14；弹窗 18；胶囊仅用于状态与计数 |
| 阴影 | xs 控件，sm 轻选中，md 菜单，lg 弹窗；正文不叠多层阴影 |
| 阅读宽度 | 常规上限 760；PDF 画布由缩放控制，宽表格允许局部横向滚动 |

对齐先看内容起始线，再看外框。表格文字左对齐，数值右对齐，状态保持同列；不要把长段文字居中。默认不在卡片内再套卡片。

## 4. 页面骨架与空间分配

### 4.1 全局骨架

- 左侧主导航保持检索工作台、文献库、综述工作台、文献问答、阅读与笔记；任务中心、设置位于下方。
- 项目选择、新建和删除属于项目菜单。综述工作区选择只在综述页，文献选择只在阅读页。
- 顶栏高度 52，保留面包屑、主题切换与窄屏导航入口。正常保存信息不常驻；保存失败必须在可见位置提示。
- 不重复显示相同的页面名、项目名和说明。已有明确工作区名称时不再叠加大号“综述工作台”标题。

### 4.2 三种内容骨架

| 骨架 | 页面 | 组织方式 |
| --- | --- | --- |
| 管理型 | 文献来源、文献库、任务中心 | 页头 → 操作/筛选 → 列表；紧凑便于比较 |
| 文档型 | 综述、阅读与笔记 | 对象选择 → 局部工具栏 → 目录/正文/按需检查栏；正文获得剩余高度 |
| 对话型 | 检索助手、文献问答、阅读聊天 | 对话列表 → 当前对话标题与模型 → 消息 → 固定可见的输入区 |

文档正文、目录、证据可以独立滚动；普通设置页优先一个主滚动区域。避免在一张小卡片中出现多个滚动条。证据侧栏用于核对，不改变当前正文选中位置。

### 4.3 窄窗口策略

由可用空间决定布局：先换行或收纳低频操作，再将辅助侧栏改抽屉，最后折叠全局导航。不要首先缩小字体或隐藏主要动作。抽屉关闭入口始终可见，Escape 关闭最上层浮层后恢复焦点。

当前综述证据栏在小于 1400px 时采用抽屉，900px/600px 有紧凑适配；这些是已有实现，不要求所有页面套用相同断点。统一验收 1440×940、1024×768、760×900；360px 用于控件与窄布局压力检查，不代表产品已经承诺完整手机体验。

## 5. 操作层级：位置先于装饰

### 5.1 位置契约

| 操作范围 | 位置 | 示例 |
| --- | --- | --- |
| 对象管理 | 左上方，紧邻对象选择器 | 综述工作区 → 新建综述工作区 → 更多 |
| 当前任务 | 对象或标签下方左侧 | 更新检索；准备材料 / 开始撰写 |
| 结果查看 | 正文上方左侧工具栏 | 全文预览 → 导出 → 已保存稿件 |
| 局部内容 | 紧邻对应行、章节、消息 | 复制回答、重写本组章节、查看证据 |
| 辅助面板 | 靠近其入口与面板边界 | 目录切换、证据关闭 |
| 状态计数 | 相应工具栏右侧 | 全文 18 / 32 节完成 |
| 对话发送 | 输入区右下；始终可见 | 发送 / 停止生成 |
| 弹窗提交 | 底部尾端，取消在确认前 | 取消 → 保存设置 |

“左对齐”适用于页面常用操作，不是所有动作都左移。位置表达作用范围；用户无需回到页头才能操作一条消息。

### 5.2 按钮优先级

| 级别 | 外观 | 使用条件 |
| --- | --- | --- |
| Primary | `--accent` 实底 + `--on-accent`，同组最多一个 | 此刻推进主要任务的动作 |
| Secondary | surface 底 + 细边框 | 常用辅助动作，如添加、设置 |
| Tertiary | 无常驻底，文字/图标 | 查看、复制、预览、导出 |
| Overflow | 省略号入口、完整文字菜单项 | 低频管理与恢复操作 |
| Destructive | 菜单红字，最终确认红底 | 删除、不可逆清空；停止任务不默认红底 |

每个页面初始视野应有明确主动作；设置弹窗打开时，弹窗的主动作接管注意力。选中标签可以有强调色，但不能像第二个“执行”按钮。

尺寸和形状不随重要性任意变化。工具栏统一 32；工作区管理组统一 36。使用 `.action-bar` 统一几何，不给每页主按钮额外加高。

### 5.3 所有按钮必须覆盖的状态

| 状态 | 契约 |
| --- | --- |
| 默认 / 悬停 / 按下 | 使用公共 token，操作名不跳动 |
| 键盘焦点 | 清楚的 focus-visible，不只改变文字色 |
| 禁用 | 真正阻止执行；关键前置条件在附近可读，不能只靠禁用按钮的悬停提示 |
| 处理中 | 保持原位置，阻止重复提交；可停止时提供停止入口 |
| 完成 | 反映真实结果；不同时弹出多个重复成功提示 |
| 错误 | 保留输入与已完成内容，在原操作附近提供可行恢复入口 |

图标按钮必须有可访问名称。重要或低熟悉度动作默认“图标 + 文字”；省略号命名为“工作区更多操作”等具体范围。无需给每个按钮附加图标。

## 6. 渐进展示：选择正确的容器

| 情况 | 容器 | 边界 |
| --- | --- | --- |
| 少量低频命令 | 更多菜单 | 主流程不能只有菜单入口；尽量一层，最多一层子菜单 |
| 多个相关参数 | 设置窗口 | 有明确标题、字段标签、取消/保存；不要把表单塞进命令菜单 |
| 偶尔查看的过程 | 折叠区 | 折叠时仍有摘要，例如成功/失败数量 |
| 边读边核对 | 侧栏 / 窄屏抽屉 | 例如引用证据；关闭后恢复正文上下文 |
| 大量可选对象 | 可搜索选择列表 | 文献按标题和 PMID；不要无限延长菜单 |
| 不可逆决策 | 确认弹窗 | 写清对象、范围、后果；最终按钮叫“删除工作区”，不叫“确定” |

菜单按任务分组，危险动作最后；必要时一条分隔线。文字遵循“动词 + 对象”，不用哈希、脚本名和内部目录名当命令。

原生 details + 普通按钮可以作为简单展开菜单；若改为 ARIA menu，必须完整实现方向键、Home/End、Escape 与焦点管理，不能只添加 role。选择器与命令菜单不同：选值使用 Select/listbox，不混入“删除当前对象”。

## 7. 表单、弹窗与保存

- 字段使用可见 label，placeholder 只举例，不能代替字段名；可选项标“可选”。
- 数值字段显示单位、有效范围及当前值；错误靠近字段，说明如何纠正，不只显示“无效参数”。
- 模型选择展示服务名称与模型，使用设置中已配置选项；缺少配置时提供进入设置的入口。
- 即时生效偏好与需保存的批量参数不得混用。撰写设置保持“保存后生效”，取消恢复已保存参数。
- 关闭未保存编辑遵循已有离开保护；不得因点击遮罩悄悄丢弃草稿。尚未覆盖的入口需按迁移计划补齐。
- 弹窗有标题、可见关闭入口、正确的名称关联和焦点约束；关闭后回到发起控件。长表单滚动内容，主要动作保持可达。
- 多行输入中 Enter 换行，⌘/Ctrl+Enter 发送；输入法组合阶段不能触发发送。Escape 优先处理最上层浮层，不删除输入。
- 正常保存不占全局顶栏；存在未保存编辑时在对应对象附近提示；保存失败持久可见，解决后消失。不得用短暂 toast 代替失败状态。

## 8. 任务状态与研究成果状态

### 8.1 分开表达三个维度

1. **运行状态**：这次操作是否结束，例如处理中、已停止、部分完成。
2. **成果时效**：成果是否对应当前输入，例如最新、需更新。
3. **材料类型**：现在可用什么，例如 PDF 全文、摘要、未准备。

“下载任务完成”不等于“所有文献都有 PDF”；“本轮 100%”不等于“整篇综述完成”。保持现有后端判定，UI 不通过颜色或百分比重新推断。

### 8.2 统一呈现词汇

| 状态 | 呈现 | 可提供的下一步（以接口支持为准） |
| --- | --- | --- |
| 未开始 / 待处理 | 中性文字 + 待处理标记 | 开始 / 准备 |
| 排队中 | 中性文字 | 查看任务；支持时可取消 |
| 处理中 | 阶段文字 + 动态标记 / 可确定的进度 | 停止 |
| 正在停止 | 原位文字，防止反复请求 | 等待本次停止完成 |
| 已停止 | 中性文字 + 保留成果数量 | 继续或重新开始；不能混称恢复 |
| 已完成 | 勾选 + 完成数量 | 查看结果 |
| 部分完成 | 注意色 + 成功与失败数量 | 重试失败项 |
| 失败 | 错误图标 + 原因 + 影响范围 | 重试 / 检查设置 |
| 需更新 | 注意色 + 变更原因 | 更新；仍允许查看旧成果 |
| 未知 / 读取失败 | 明确表示无法获取状态 | 重新读取；不能显示为 0 或已完成 |

未知总量用阶段文字与不定进度，不模拟百分比。可数进度写清“篇 / 节 / 组”；分母变化时解释来源，不暗示进度倒退就是失败。

开始任务后仅锁定冲突操作，保留阅读、查看结果和导航。能否离开页面继续运行必须依据该任务真实生命周期；不得给所有任务统一承诺后台运行。

### 8.3 反馈矩阵

| 事件 | 反馈位置 | 持续方式 |
| --- | --- | --- |
| 复制成功 | 原按钮附近 / 单条轻提示 | 短暂，不遮盖正文 |
| 导出完成 | 轻提示 + 可定位的结果 | 提供文件位置或打开入口；不在正文暴露长路径 |
| 表单校验失败 | 字段附近 | 修正前保留，关联 aria-describedby |
| 单项任务失败 | 对应行或任务详情 | 可恢复前保留，不阻塞其他成功项 |
| 保存失败 | 当前编辑区域或全局异常条 | 成功恢复前保留 |
| 删除或覆盖 | 事前确认 / 既有保护流程 | 明确范围，不能宣称不存在的撤销能力 |

## 9. ScholarNoteLM 页面契约

| 页面 | 主要内容与主动作 | 设置/详情的归属 |
| --- | --- | --- |
| 文献来源 | 来源列表；更新检索在左侧 | 添加、Zotero、批量筛选、导出 XML 同页；全量重检与归档在更多 |
| 检索助手 | 研究问题与对话；发送 | 对话管理在对话侧栏；模型在当前对话标题区域；无公共 XML 导出 |
| 文献库 | 篇名与准备状态；一键更新文献 | PDF、转换、索引各阶段局部操作与报告；不恢复无 PDF 条目的单篇下载按钮 |
| 综述大纲 | 工作区选择、大纲树；生成或编辑 | 已有大纲时默认收拢生成设置；CSV/恢复在更多；不隐藏正在编辑的错误 |
| 综述撰写 | 目录与正文；按状态准备/撰写/停止 | 模型/并发/每节片段数在设置，摘要可见；证据按需打开 |
| 文献问答 | 回答、引用、持续可见的输入区 | 对话管理、模型选择；新提问沿用主题问答，不恢复概览模式开关 |
| 阅读与笔记 | PDF 连续滚动或只读摘要；右侧全文聊天 | 顶部文献搜索与选择；缩放就近；PDF/摘要不可编辑，手写笔记独立 |
| 任务中心 | 各任务运行状态与恢复入口 | 详细日志按需展开；不替代页面内的任务状态 |
| 设置 | 分组参数、清楚的生效方式 | 校验与保存放在对应组，危险维护操作分开 |

```text
综述工作区

主题摘要
[综述大纲 | 综述撰写]

```

### 9.1 引用和证据

引用是阅读入口，样式可识别且可用键盘访问；展开后展示篇名、PMID、来源与对应原文。位置单位必须真实：Markdown 行号不能称 PDF 页码。原文摘录和模型生成内容在标题/标签上区分；不展示内部哈希，不恢复已删除的技术详情和冗余提示。

从其他页面打开阅读时保留原页面上下文；返回到原对话、章节或列表选择。该行为按页面逐项验收，未覆盖时列为待落实，不笼统宣称全站支持。

### 9.2 对话和长时间阅读

复制、重新生成、从这里开始分支使用相同名称与顺序；各自作用范围清楚。重新生成或分支可能调用模型，不能仅通过无文字图标触发不明确操作。沿用各模块现有记录保护语义。

流式回答只在用户停留底部时跟随滚动；用户向上阅读时不抢回底部，可提供“回到最新”。模型生成过程中保留输入草稿。PDF 缩放继续复用画布预览，清晰重绘不引起阅读焦点跳动。

## 10. 动效、性能与可访问性

### 动效

使用现有 80 / 140 / 200 / 280ms token。动效解释展开、进入、按下，不承担唯一状态表达；状态数字更新不反复闪烁。尊重 prefers-reduced-motion。页面动画结束后不残留 transform。

长列表避免因实时任务轮询全量重排；只更新相关状态。已显示内容在刷新时保留，不因为请求开始就重新显示整个空白加载页。

### 可访问性验收目标

- 普通文字对比度至少 4.5:1，大文字至少 3:1；关键控件边界、图标和焦点按实际背景检查非文本对比。此为目标，不代表已完成全站审计。
- 点击目标细指针场景至少满足 WCAG 2.2 的 24×24 CSS px 或其间距例外，产品优先采用 32px 工具栏目标；粗指针目标约 44px。
- 键盘可完成对象选择、打开菜单、调整表单、发送、取消和关闭；焦点不能被固定输入区或浮层遮挡。
- 模态窗口有正确名称和焦点约束；标签页、选择器、树、展开按钮有对应语义。原生语义优先于不完整的自定义角色。
- 关键进度和错误可被辅助技术感知；aria-live 不逐 token 播报完整长回答，不反复宣读轮询中未变化的状态。
- 深色主题独立验收；不能仅反转颜色。放大文字后按钮可换行排列，信息不能因固定高度被裁掉。

参考：[WCAG 2.2 对比度](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html)、[非文本对比度](https://www.w3.org/WAI/WCAG22/Understanding/non-text-contrast.html)、[目标尺寸](https://www.w3.org/WAI/WCAG22/Understanding/target-size-minimum.html)。

## 11. 文案与术语

| 术语 | 固定含义 |
| --- | --- |
| 项目 | 一组研究文献与相关研究成果 |
| 综述工作区 | 项目中一篇综述的独立工作范围 |
| 大纲节点 / 章节 | 大纲结构 / 面向读者的内容单元 |
| 文本块 | 从文献分块得到的原文检索单元 |
| 写作材料 | 本轮撰写使用的证据集合 |
| 已保存稿件 | 已保留的综述成果，不等同于工作区版本管理 |
| 保存 | 更新应用管理的内容 |
| 导出 | 生成可在应用外使用的文件 |
| 归档 | 从当前视图移出，保留可恢复内容 |
| 删除 | 按确认的范围删除，不能与归档混用 |
| 重试 | 再执行失败部分；若会全量重做，必须写明 |

错误文案采用“发生什么 + 影响范围 + 下一步”，例如“有 3 篇 PDF 获取失败，已完成的 18 篇已保留。可重试失败项。”数量必须来自真实结果。避免“操作失败”“系统异常”作为唯一内容。

提示只出现在帮助做决定的位置，不重复解释按钮字面含义。不把开发细节放进产品主流程；诊断信息进入按需展开的报告。

## 13. 迁移顺序与完成判据

### 已有基础

现有 tokens、浅深色、公共 Select/Modal/ActionMenu、检索与综述 action-bar、综述紧凑布局作为起点。现状依据本次源码检查；不能推断所有页面已满足本文。

### 分阶段落实

1. **组件和视觉收敛**：盘点按钮、字号、图标、间距和颜色例外，优先工具栏与表单；用公共样式替换重复规则。完成判据：相同操作在检索/综述/问答/阅读拥有相同外观与作用范围。
2. **状态和反馈收敛**：统一任务词汇、失败提示、禁用原因、未知状态和真实进度。完成判据：下载结束但无 PDF、部分综述完成、输入改变导致需更新等情况不产生歧义。
3. **交互收敛**：逐页审计弹窗草稿保护、焦点恢复、对话动作、页面返回、滚动记忆。完成判据：鼠标与键盘都能完成同一流程，离开或返回不意外丢失编辑。
4. **密度与适配**：检查窄窗、长标题、中英文混排、大纲深层级和深色对比。完成判据：主动作和输入区可达，正文不被设置或浮层永久挤走。

视觉收敛只改样式；改变导航、保存、删除或任务行为时单列功能变更，遵循用户授权和现有产品约定，不能夹带在“美化”中。

### 每次改动的验收清单

- 当前对象可辨认；主动作唯一且位置稳定；局部动作没有跨越作用范围。
- 页面常用功能不必先打开更多；菜单没有因为窄窗口而越界。
- 同排按钮高度、字重、图标、间距统一；按钮与状态标签不会混淆。
- 使用真实状态和单位；失败、无数据、未知、加载分别有明确表达。
- 支持键盘、中文输入法、Escape 与焦点返回；必要的未保存保护仍生效。
- 浅深色、长内容、窄窗、放大文字均检查；没有主要操作只在 hover 出现。
- 研究数据、引用、缓存签名和自包含导出行为保持现有约定。
- 在隔离项目中验证；不调用用户真实模型或修改真实研究项目。
- 采用范围合适的构建/功能测试与截图；不声称未做过的可访问性或平台验证。

## 14. 实现约束与参考

通用样式写入 design.css；页面文件仅负责特定结构。不要给包含 position:fixed 子元素的容器加 backdrop-filter 或常驻 transform；动画使用 backwards 填充，结束后不留下新的定位包含块。浮层需要避让窗口边界，菜单不被正文 overflow 裁切。

仅更新开发版，除非用户明确要求发布。规范与 token 改动应纳入 Git；不提交测试截图、配置、密钥或研究数据。不要为设计系统引入大型 UI 依赖、远程字体或重复资源包。

参考来源及本产品的采用方式：

- [Apple · Design principles](https://developer.apple.com/design/human-interface-guidelines/design-principles)：采用一致反馈与可访问性优先原则。
- [Apple · Layout](https://developer.apple.com/design/human-interface-guidelines/layout)：采用对齐、逻辑分组和自适应布局。
- [Apple · Toolbars](https://developer.apple.com/design/human-interface-guidelines/toolbars)：采用常用操作可见、按范围分组，控制工具栏密度。
- [Apple · Disclosure controls](https://developer.apple.com/design/human-interface-guidelines/disclosure-controls)：采用常用内容在前、细节按需展开，并保留清晰标签。
- [Apple · Feedback](https://developer.apple.com/design/human-interface-guidelines/feedback)：采用反馈重要性与打断程度匹配。
