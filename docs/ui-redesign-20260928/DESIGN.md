# ScholarNoteLM UI 方案 · 2026-09-28

状态：设计提案，尚未修改正式 UI。截图来自本次运行的源码开发界面；图像预览由内置 imagegen 生成，包含排版示意文字，不能作为论文元数据、研究结论或真实任务状态使用。尺寸与颜色以本规范为准，生成图并非像素级验收稿。

## 设计判断

当前界面的主要问题不是单个色值，而是视觉层级与工作流不匹配。

1. 绿色背景、深绿色导航、表头、按钮与用户气泡重复占据重点；次要正文偏灰，层次靠填色而非排版。
2. 概览的大横幅、轨道插画、重复项目名称和常驻口号占用研究空间。
3. 1280×720 的文献库首屏几乎看不到文献，四张流程卡片的高度过大。
4. 综述同时叠加全局侧栏、工作区列表、章节目录；主题表单与写作参数挤压实际大纲和正文。
5. 设置存在大容器套小容器，字段、说明、按钮分散；高频保存和验证的位置不稳定。
6. 聊天中标题、模型、过程、回答、引用、工具拥有过多层级；窄窗口中对话侧栏遮挡阅读与输入。
7. 圆角、按钮高度、字重、阴影、间距由多个样式文件覆盖，缺少统一语义。

目标是适合长期阅读、检索和写作的桌面研究工具：纸白、石墨、银灰、少量墨蓝；让内容和状态成为视觉主体。

参考 Apple 的控件一致性、克制用色、分栏和可访问性。数值是为本项目制定，不是 Apple 官方要求。不直接复制系统外观，不把 Liquid Glass 铺在论文与表格上。

## 1. 动画规范

| 场景 | 时长 | 行为 |
|---|---:|---|
| hover / pressed | 100–120ms | 仅背景、描边、图标颜色变化；按钮不跳动、不放大 |
| 下拉菜单 / tooltip | 140ms | 淡入，最多 4px 位移；tooltip 延迟 500ms |
| 页内标签切换 | 160ms | 下划线/选中底色过渡；内容淡入，不横向飞入 |
| 折叠区 / inspector | 200ms | 面板推入或覆盖；内容布局只在明确用户操作时改变 |
| 对话框 / sheet | 220ms | opacity + translateY 8px；背景遮罩同步 |
| toast | 180ms | 淡入，最多 6px 位移；自动消失前留足阅读时间 |
| 已知进度 | 180–250ms | 平滑更新真实进度，不模拟增长 |
| 流式回答 | 即时 | 文本直接追加；不逐字淡入、不重复播放段落动画 |

- 常规 easing：cubic-bezier(.2,.8,.2,1)；退出可采用 cubic-bezier(.4,0,1,1)。不用弹跳和大幅 overshoot。
- 不使用 transition: all；优先 opacity / transform。拖拽分栏直接跟随指针，不加延迟。
- 后台轮询、保存反馈和数据刷新不重播进场动效；不抢走用户历史阅读位置。
- loading 保持按钮原宽度，spinner 替换图标，文字明确说明动作；不得改变布局。
- prefers-reduced-motion 下移除平移、缩放、平滑滚动和循环旋转；保留文字状态/静态进度反馈。
- 动画不阻塞点击、键盘或取消任务；切页记住相应滚动位置。

## 2. 按钮与控件规范

| 类别 | 样式 | 用途 |
|---|---|---|
| Primary | 墨蓝底、白字、无厚重阴影 | 当前上下文最重要动作；同一操作区最多一个 |
| Secondary | 白/表面色、清晰细描边、石墨字 | 导入、导出、验证连接、准备材料 |
| Tertiary | 透明底、灰黑字，hover 浅灰 | 展开、复制、查看报告、返回 |
| Destructive | 常态普通菜单项，确认时红字/红底 | 删除、清空；不与主要动作并列抢眼 |
| Icon | 同尺寸透明/描边容器 | 切换布局、目录、更多；必须有 accessible name 与 tooltip |

- 默认按钮高 34px，密集工具栏 28px，重要对话框 38px；同一组高度一致。
- 左右 padding 12px；图标 16px，图标与文字间距 6px；圆角 7px。
- 图标按钮可见尺寸 28/32px，命中区至少 32px；触控布局至少 44px。
- 输入框、下拉框、数字输入默认 34px，采用同一边框、圆角、字体与 focus ring。
- hover 改变表面色；pressed 加深 4–6%；disabled 有真实 disabled 语义，并提供不可用原因。
- focus-visible：2px 墨蓝外环，offset 2px；不能只靠颜色或阴影表达状态。
- 按钮标签使用明确动词：执行检索、更新文献、准备材料、生成综述、保存配置。
- 导航项/标签页不冒充提交按钮；筛选 badge、状态 badge 和按钮分别定义。
- 复制、分支、重试等次级消息操作收在回答末尾工具行；hover/focus 可增强，不能完全依赖 hover 才可发现。

## 3. 布局规范

全局采用应用栏 + 内容工具栏 + 工作表面的三层结构，移除常驻宣传页脚。

- 标准桌面导航宽 184–208px；专注模式 56px 图标栏。长项目名省略但有完整 tooltip。
- 顶栏 48px，页内工具栏 48–56px。页标题与操作合并在同一视觉行，不重复 breadcrumb 的全部信息。
- 页面边距 24px；空间刻度 4/8/12/16/24/32/48。普通分组之间24px，字段之间16px。
- 内容区优先开放排版和细分隔线；只有需要明确归属、浮层或独立选择的区域才用容器。
- 面板圆角10px，弹窗12px；普通数据行不各自画圆角卡片。
- 一屏只有一个主要纵向内容滚动区域；目录/会话列表和 inspector 可独立滚动，避免嵌套滚轮陷阱。
- 聊天输入区固定在本地聊天面板底部，安全区与滚动 padding 一致，不能覆盖最后一段正文。
- 表格采用 sticky header，行高56–72px（双行标题），单元格12px；论文标题主列优先宽度，作者省略。
- 作者、日志路径、模型技术细节通过展开或 inspector 查看，不在高频界面持续铺开。
- 正文阅读宽度约640–760px；中文约35–45字/行；宽表格在自身区域横向滚动，不撑破页面。

响应式行为按可用内容宽度决定，而非简单缩小文字：

| 宽度 | 行为 |
|---|---|
| ≥1500px | 可展开全局导航、目录、正文与证据 inspector |
| 1200–1499px | 问答证据默认抽屉；综述可用56px导航 + 目录 + 正文 +窄证据栏 |
| 900–1199px | 收起全局导航；证据以覆盖抽屉出现；会话/目录可收起 |
| <900px | 单内容面板；导航/会话/证据按需覆盖并有关闭、遮罩和焦点管理 |

保留用户主动选择的分栏状态；只有变窄导致正文低于最低可读宽度时折叠辅助面板，不遮挡输入框。

## 4. 配色规范

| Token | 浅色 | 深色 | 用法 |
|---|---|---|---|
| canvas | #F5F5F7 | #191A1E | 应用底层 |
| surface | #FFFFFF | #23242A | 内容、表单 |
| sidebar | #F0F1F3 | #202126 | 导航层 |
| reading | #FAFAFB | #24252A | 长文阅读底 |
| text-primary | #1D1D1F | #F0F1F4 | 标题与正文 |
| text-secondary | #62666E | #A8ADB8 | 次要说明、metadata |
| accent | #3157D5 | #91ACFF | 主动作、链接、焦点 |
| accent-soft | #E9EEF9 | #2C3552 | 选中项底色 |
| separator | #DEE0E5 | #3B3E48 | 分隔结构 |
| control-border | #8B909A | #757D8D | 需要辨识的输入边界 |
| warning | #8B5A14 | #E4B56C | 摘要替代、部分完成、过期 |
| danger | #B3363F | #FF8992 | 失败、破坏性操作 |

- 中性色占绝大部分。墨蓝只用于交互和选中，不给所有非交互标题染蓝。
- “已完成”优先使用灰色勾和明确文字，不把整页染绿；原论文图表中的颜色不更改。
- 成功、失败、等待、摘要替代必须同时有文字/图标，不能仅靠颜色。
- 辅助分隔线可以低对比；用于识别控件和焦点的边界必须单独验证3:1对比。
- 正文与主要控件文字目标至少4.5:1，大字至少3:1。禁用态不作为可读性基准。
- 深色模式单独定义层级，不对浅色界面简单反相，不添加彩色光晕。
- 普通面板不用投影；菜单/对话框可使用0 8px 24px rgba(20,24,35,.12)加细描边。
- 透明材质仅可轻用于工具栏/临时浮层；正文、表格、表单始终保持稳定背景。

## 5. 字体规范

UI 使用系统字体栈：-apple-system, BlinkMacSystemFont, "SF Pro Text", "PingFang SC", "Segoe UI", "Microsoft YaHei", sans-serif。

论文标题/阅读正文可使用："Iowan Old Style", "New York", "Songti SC", "STSong", Georgia, serif；不得依赖未安装字体，不打包未经授权的 Apple 字体。中文长文默认平稳的系统无衬线，可后续增加阅读字体偏好。

检索式/PMID/技术路径使用：ui-monospace, "SFMono-Regular", Menlo, Consolas, monospace。长数字启用 tabular-nums。

| 层级 | 字号/行高 | 字重 |
|---|---|---|
| 页面标题 | 26/34px | 600 |
| 阅读文章标题 | 28–32/40px | 500或600 |
| 区域标题 | 17/24px | 600 |
| 文献标题 | 15/22px | 500 |
| 普通UI/按钮 | 13–14/20px | 400/500 |
| 问答/综述正文 | 16/27px | 400 |
| 摘要阅读 | 17/29px | 400 |
| 元数据/帮助 | 12/18px | 400 |
| 检索式 | 12–13/20px | 400 |

- 不使用极细字重，不用10px灰字承担重要信息，不用全大写英文口号装饰界面。
- 汉字不加装饰性字距；标题轻微英文tracking只在需要时使用。
- 统计数字用系统无衬线，不再与阅读区衬线混用。
- 保留200%文字放大的布局能力；表格和代码可横向滚动，按钮可换行分组。

## 工程实施顺序（待视觉方向确认）

1. 建立单一语义token源：颜色、字体、间距、圆角、层级、动效、断点；移除以green命名的品牌token依赖。
2. 统一Button/IconButton/Input/Select/SegmentedControl/Badge/Menu/Sheet组件；涵盖focus、loading、disabled、danger。
3. 重构AppShell/Toolbar/SplitView/Inspector/Composer；不改变RPC和数据生命周期。
4. 先落地文献库、问答、综述正文，检验高密度与长文本；再适配检索、概览、阅读、任务与设置。
5. 将现有refinements/readability等覆盖规则逐步归并；不用末尾再追加一层主题覆盖来完成改版。
6. 在1280×720、1440×900和窄窗，以及浅/深色、200%文字、减少动态效果、键盘路径下验收。

验收要求：首屏论文可见；输入区始终可见；运行状态不会挤动正文；危险动作不丢失；所有既有工作流入口仍可达；无新模型请求；不改动研究文件。静态图不能证明动画实现，动效需要代码演示与实际UI验收。
