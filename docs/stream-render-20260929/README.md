# 检索助手流式交互优化 · 2026-09-29

## 已修复

- Markdown 检索式卡片使用稳定组件。流式更新不再替换按钮 DOM，避免鼠标按下和松开之间收到新内容时丢失点击。
- 历史回复独立缓存渲染；折叠的思考内容不解析 Markdown，正在生成的思考使用轻量文本显示。
- 后端约 40 ms 合并发送完整快照，前端约 50 ms 合并显示更新，结束时保留完整尾部。
- 每条检索式独立显示保存状态，防止重复提交；保存不阻塞继续生成，失败可重试。
- 增加本机内存中的有限时间诊断：开发工具调用 `window.scholarSearchStreamDiagnostics()`，区分消息接收间隔、传输延迟与渲染延迟。不记录回复正文或密钥。

## 验证

- TypeScript / Vite 构建通过；macOS 桌面包构建及签名校验通过。
- Rust research-cli：17 项测试通过。
- 本地受控 SSE 测试：8 组场景通过，包含正常、长思考、取消、截断错误、200 个快速增量无丢失、流式期间独立保存检索式（约 69 ms）。未调用用户的付费模型。
- WebKit / Chromium UI 回归均通过：历史和当前检索式按钮在按下／松开之间经历输出仍可保存；单条保存与流式并行；保存失败重试；滚动暂停及恢复；最终尾部完整；关闭的思考内容不渲染。
- 长思考受控压力场景（约 2.2 秒）：WebKit 最大帧间隔 23 ms，Chromium 约 16.8 ms。此结果仅代表本地测试，不保证服务商持续输出。
