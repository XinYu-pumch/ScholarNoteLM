# 提示词准备性能修复与验证

2026-09-30，项目 `workspace/PrimaryMN/review/MN`。

## 原因与修复

原来的取消检查同时每两秒计算整个项目的材料签名。该检查被配额等待、HTTP 轮询、任务更新等高频路径调用。PrimaryMN 有 227 篇 Markdown，而 Markdown 解析缓存只能容纳 128 篇；顺序扫描造成缓存反复淘汰。一次扫描约 2.25 秒，超过两秒的检查间隔，因而再次检查时又启动全文扫描。HTTP 协程也会被同步扫描阻塞。

现在高频回调只检查取消。材料有效性检查移至工作线程，并以文件身份（inode、大小、纳秒 mtime/ctime）及依赖清单复用本次任务的核验结果。首次检查、依赖变化后仍计算完整内容签名；保存召回结果、保存材料包、发送正文及修复请求、发布正文前均核验。全文、摘要、文献集合、转换、索引、图像和模型配置变化均覆盖；不使用 UI 的过期快照或 TTL 授权保存或发送。检查期间持续变化则停止发布。

新增有容量限制的图片引用缓存，只存文本摘要及引用路径，不额外缓存整篇 Markdown 或语法树。图片文件自身仍依据实际文件状态校验。原有资源指纹、材料签名和材料格式不变。

终末标题原文、bge-m3、余弦排序、每标题前 7 块、共享证据去重、关联图表与写作要求均不变。修改没有添加召回模型、重排或写作 LLM 调用。

## 真实项目的隔离测试

读真实索引的 16,987 个可召回文本块、135 个终末标题、46 个写作单元。输出写入临时目录；原项目综述目录在测试前后逐文件计算摘要，确认完全不变。

| 测试 | 耗时 | CPU 时间 | 完整材料扫描次数 |
| --- | ---: | ---: | ---: |
| 旧实现，复用召回结果，仅准备前 3 个单元 | 60.64 秒 | 60.55 秒 | 24 |
| 新实现，复用召回结果，准备全部 46 个单元 | 2.96 秒 | 2.83 秒 | 1 |
| 新实现，回放 135 个标题的召回结果，准备全部 46 个单元 | 6.48 秒 | 6.41 秒 | 1 |

所有生成材料包的 JSON 内容与已有材料逐一相同。以上测试预加载相同的索引记录，跳过启动时的索引同步；第三项使用已有召回结果模拟返回并执行高频取消检查，**不包含真实服务器延迟，不代表实际联网端到端耗时**。没有请求远程模型。原任务历史总耗时 2,365.21 秒包含真实网络及整个流程，不能与上表直接计算加速倍数。

单次完整材料签名：旧实现 2.25 秒；新实现冷缓存 2.29 秒，热缓存 0.77 秒。关键收益来自消除高频重复扫描，而不是省略首次有效性核验。

原始计时见 [timings.json](timings.json)。可复现实验脚本在 `tmp/benchmark_prompt_fix.py`，读取该项目当时的快照；如果材料已更新，脚本会拒绝继续比较。

## 后续：文献问答采用相同核验方式

同日将 `qa_service.py` 和 `qa_mini_review.py` 接入同一任务内的材料核验 Guard：

- 高频 HTTP、配额等待及取消回调仅检查取消，不扫描原文或读取全部索引。
- 完整核验通过 `asyncio.to_thread` 在后台执行；文件依赖未变化则复用核验结果。
- 召回前后、模型请求发送前（含修复请求）、响应保存前，以及所有答案完成出口核验材料。普通回复、历史改写、无证据回答、结构化问答、逐篇阅读和停止可选深度核查后保留答案的分支均覆盖。
- 文献、Embedding 或模型配置变化会阻止后续发送或发布；该类错误不会作为格式错误降级处理。网络请求已发出后发生的材料变化在请求返回时拦截，不把流式草稿视为已完成答案。
- 保持既有召回范围、排序、topK、轮数、共享池和引用格式；未改动启动时已有的文献加载与索引同步流程。

PrimaryMN 真实材料只读测量：热缓存下，10 次完整问答签名检查共 7.809 秒（CPU 7.784 秒）；10 次 Guard 核验共 1.058 秒（CPU 1.053 秒），仅计算一次完整签名。这个数字只衡量材料核验，不代表整次联网问答耗时。

验证：91 项 `test_qa*.py` 测试全部通过。其中新增 6 项使用真实 XML 变更，覆盖高频回调零扫描、完整核验在非事件循环线程执行、发送前变更、流式期间变更、发布前变更、模型配置变化及取消操作。旧有“修复期间材料变更”测试也改为真正变更依赖文件，而非只改变内存中的模拟返回值。

当前流程的 `scripts/test-qa-mini-review-integration.py` 通过独立 worker、本地 Embedding/SSE 服务验证召回、材料去重、结构化答案、引用、导出和历史改写，并新增验证：活动 HTTP 在 2 秒内取消；流式期间修改 XML 后，不生成正式答案或 `answer-section.json`。测试没有调用外部模型或修改用户项目。
