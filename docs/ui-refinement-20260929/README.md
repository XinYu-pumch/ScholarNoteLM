## 模型选择行为

- 配置池中只有一个全局默认模型，由“配置 ID + 模型 ID”共同确定；修改其他服务配置不会夺走默认位置。
- 首个可用模型自动成为默认。删除默认模型或配置时，回退到剩余可用模型；没有可用模型时不保留无效默认。
- 检索助手、综述大纲、综述撰写、文献问答各自有下拉菜单。未指定时沿用全局默认。
- 检索助手选择按项目保存在本地，大纲选择按项目与综述工作区保存；撰写选择随该工作区参数保存，问答沿用原有问答设置持久化。
- 撰写选择或参数修改后点击“保存参数”生效。设置中的模型增删、图片能力和默认模型在“保存配置”后生效。
- 大纲和撰写后台任务固定启动时的模型 ID；切换全局默认不会让这些任务悄悄改用其他模型。
- 切换撰写模型不会使已准备的共享材料包失效，正文仍按实际模型签名判定是否最新。
