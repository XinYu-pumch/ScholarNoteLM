# ScholarNoteLM UI 设计说明

## 方向：安静、有秩序的研究空间

采用暖白与浅灰绿底色、墨绿色强调色，以低对比边框分隔信息，避免大量高饱和色块。工作区排版紧凑，正文与文献标题保持阅读空间。

- 品牌标识：书页与知识连接的线性图形。
- 基础字体：系统无衬线字体，兼容 macOS 和 Windows 的中文排版。
- 大标题与阅读场景：选择性使用系统宋体/Georgia，增加阅读感。
- 图标：Lucide 线性图标，本地依赖，不发起远程请求。
- 动效：只用于轻量反馈与进度，尊重系统减少动态效果设置。
- 色彩变量：`apps/desktop/src/tokens.css`，同时包含浅色和深色主题。

## 页面与交互

| 页面 | 设计目的 |
|---|---|
| 项目概览 | 回到研究目标，继续阅读或开始写作 |
| 文献库 | 以文献标题为中心，快速筛选、收藏和处理 |
| 阅读与笔记 | 原文内容与个人思考并排，保留来源上下文 |
| 文献问答 | 问题和答案居中，右侧提供可追溯来源 |
| 综述工作台 | 左侧大纲、中间草稿、右侧章节证据 |
| 任务中心 | 真实后台任务进度、取消、继续与日志 |
| 设置 | 模型与服务、Embedding、转换、问答和存储设置 |

桌面布局优先。窗口收窄时导航折叠，问答来源变为抽屉；较窄的综述窗口可通过顶部“证据”按钮收起覆盖面板。

## 当前交互（2026-09-28）

- 问答与检索助手使用紧凑、可折叠侧栏，长标题省略。对话目录按问题编号、搜索和跳转，输入框始终可见；历史阅读不会被轮询抢走位置。
- 模型启用、支持图片、默认模型与测试放在同一模型行。技术细节集中在高级设置和来源详情；普通操作只说明必要结果。
- 文献库“更多”使用独立浮层，不撑高其他卡片；支持键盘与点击外部关闭。
- 问答和综述读取真实模型输出，引用绑定真实保存的证据。模型未返回的内容、推理和图像理解结果不得补造。结构检查不代替学术判断。

## 早期原型记录（已被当前实现取代）

以下保留最初原型阶段说明，其中“预设回答”“未来模型”“尚待接入”不适用于当前开发版。现行入口见 [文档索引](README.md)。

### 数据真实性

合成示例统一使用 `DEMO-` 标识，内置摘要明确说明并非真实论文。全局提供“交互原型”说明。问答与生成使用预设内容，不掩饰为真实模型输出。XML 导入记录使用 `PMID-` 标识；其内容仍不会被原型问答当成已检索证据。

### 已实现的有效操作

所有主导航与快捷入口可访问。筛选、排序、收藏、项目隔离、笔记编辑、大纲增补/排序、草稿编辑与导出会产生真实的原型状态变化。未接入的模型能力在设置中显示“待接入”。

### 下一轮可评审的问题

1. 暖白/墨绿风格是否符合预期，还是倾向更冷静的灰白风格？
2. 文献列表的信息密度、字号和标签是否合适？
3. 问答来源是否默认展开，综述证据是否需要更大的阅读宽度？
4. 综述编辑是否需要富文本工具栏、批注与修订模式？
5. 首屏更适合默认打开文献库，还是项目概览？

这些是下一轮设计讨论点，不影响当前原型运行。当前视觉方向尚待用户确认。
